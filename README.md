*Explicación de pseudo clases, identificadores.*

Las pseudoclases son palabras que se ponen después de un selector CSS (con dos puntos) para cambiar el estilo de un elemento según su estado. El caso típico es `:hover`, que cambia cómo se ve un enlace cuando el cursor pasa por encima, como en `nav a:hover` para los links del menú. También está `:visited`, que cambia el color de un link ya visitado, y `:focus`, que le pone un contorno a un elemento cuando se selecciona con el teclado. Un ejemplo propio sería `.galeria img:hover`, que baja la opacidad de las imágenes de la galería al pasar el mouse, dando un efecto interactivo sin usar JavaScript.

Los identificadores (`id`) en cambio sirven para ponerle un nombre único a un elemento HTML, por ejemplo `<section id="inicio">`. Desde el CSS se llaman con `#`, así: `#inicio { padding: 2em; }`. En la página se usaron para armar las secciones y poder navegar con links internos, como `<a href="#podcast">` que lleva directo a `<section id="podcast">`. Así también existen otros ids como `premisa`, `causas`, `geopolitica` y `propuestas`, cada uno marcando una parte distinta de la página. Incluso se puede usar `#podcast { scroll-margin-top: 4.5em; }` para ajustar cómo se ve la sección cuando se llega a ella por un enlace.

La diferencia entre uno y otro es que el id identifica un elemento puntual (`#podcast`), mientras que la pseudoclase describe un estado (`:hover` indica que el cursor está encima, no señala qué elemento es).
